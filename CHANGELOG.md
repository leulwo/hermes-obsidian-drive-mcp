# Changelog

Releases follow Semantic Versioning (`MAJOR.MINOR.PATCH`): patch releases fix bugs, minor releases add backward-compatible features, and major releases may introduce breaking changes.

## 1.1.0 - 2026-09-27

- Removed Drive-side note creation because Richard's Google Drive Sync plugin does not reliably adopt externally created files.
- Retained existing-note reading, search, editing, append, move, history, and opt-in deletion capabilities.
- Changed the live integration check to read-only.
- Standardized the MCP/package version at `1.1.0`.
